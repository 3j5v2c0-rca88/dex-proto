# Восстановленный проект из бинарного файла ```dex-model.pb```.
Этот проект является восстановленным по данным из бинарного файла ```dex-model.pb```. Изначально, этот файл представлял собой **скомпилированный бинарный дескриптор** ```(Protocol Buffer)```, который был восстановлен ~99% путем **реверс-инженеринга.**
# Отладочные символы, и ```SourceCodeInfo```.
По отладочным символам (типа ```SourceCodeInfo```), мы смогли **почти полностью восстановить** проект из бинарного дескриптора, и даже имена оригинальных файлов, расположение полей, и ТД. Единственное что восстановить без сторонних файлов **не удалось**, это: 
- Комментарии; 
- Все, что было за пределами ```src/```, на этапе сборки дескриптора;
- И прочее, что восстановить **невозможно без оригинального проекта.**
# Строки, литералы, имена полей, ```package```.
За счёт того, что в дескрипторе были сохранены оригинальные строки, литералы, и ```package```, мы смогли восстановить проект ещё точнее (по крайней мере стоковые имена полей, и ```package``` которые были в файлах).
# Автор, и информация о происхождении файла.
**К сожалению, нам не удалось узнать информацию о происхождении файла, и его точное назначение.**
Имя автора можно назвать лишь **поверхностно** по package. Сказать наверняка крайне трудно. Все что удалось установить, это:

- предполагаемое назначение файла — скорее всего, схема/описание бинарного формата [dex (Dalvik Executable)](https://source.android.com/docs/core/runtime/dex-format?hl=en);
- Гипотетическое имя автора: *Dex/dex-model*;
- Смысл — описание [бинарного формата dex](https://source.android.com/docs/core/runtime/dex-format?hl=en) на языке [protocol buffer от Google](https://protobuf.dev/).
